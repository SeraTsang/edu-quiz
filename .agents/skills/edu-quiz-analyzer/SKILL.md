# 教综解析 → 模糊/易错辨析题（edu-quiz）

## 使用时机与任务边界

当用户粘贴一道或多道教综试题的**答案解析**，或**“错题题干 + 答案解析”**，要求“整理模糊点 / 易错点 / 做成辨析题 / 导入辨析题库 / 出变式题”时使用。支持教材笔记、OCR 文本（仅修复有把握的识别错误），默认不追问原题。

- **两种输入**：①仅解析；②错题题干＋解析。提供错题时，**必须围绕原题核心考点进行实质变式**，而不是复述原题。改变表述结构、主体、实例、条件或逻辑关系，但保持知识判断依据不变。
- 不用于逐字还原选择题；不根据原题选项 A/B/C/D 或“故选 C”确定**新辨析题**正误。若用户要求保留特定原话，应尊重限制，同时尽可能在其他维度变式；若严格原话与“必须变式”冲突，先说明不可同时满足。
- 输入只给解析时，也优先生成具辨析价值的独立陈述，而不是复制原句。

可选参数：
- `章节：教育学 · 第一章`（仅 JSON 章节包需要；缺省为 `教综 · 待分类`）
- `题数：N`（默认每个独立核心考点 2–3 题，整次通常 3–8 题，不凑数）
- `难度：基础/易错/模糊/易错/综合`（默认易错；“模糊/易错”强调概念边界、深度复习）
- `格式：粘贴`（默认） / `格式：JSON章节包` / `格式：只看分析`
- `补充验证：是/否`（默认否；仅在用户明确要求且可联网时核实争议、拓展或法规时效性，并注明来源）
- `变式：是/否`（默认是；**提供错题时无论设置如何均须变式**。设置“否”仅适用于只提供解析的情形，表示不刻意做额外变式）

## 核心工作流程

### 1. 从解析和错题中解构考点

1. 去除“本题考查……”“故选 C”等原选择题套话，**保留定义、条件、限定词及逻辑关系**。
2. 若提供错题题干，额外识别：**原题考点、设错陷阱、错误判断的可能原因、可变式方向**（换主体/例子、反转关系、遗漏条件、部分代整体等）。不要臆测用户具体作答心理。
3. 把材料拆为**核心命题、概念边界、相邻易混概念、典型误区、适用情境**。多段重复同一考点时合并去重。
4. 识别概念偷换、划分依据混淆、主体与客体颠倒、部分与整体混淆、必要与充分混淆、因果倒置、限定条件遗漏、情境误判、绝对化表述等机制。
5. 原材料含糊、矛盾或教材口径有差异时，提示“材料不足/教材表述可能不同”，不强行给出确定真假题；未经核实不得编造法规条款、人物、年份或文献。

### 2. 设计**变式**辨析题（必须重点执行）

对每个有价值的考点，优先搭配**定义/边界变式＋易混误判变式**，必要时加入**情境迁移变式**。正确与错误自然分布，不机械凑 1:1。

| 策略 | 示例：原材料考“教育影响包括内容和手段” |
| --- | --- |
| 更换主体/实例 | 由概念叙述改为“教师用多媒体展示教学内容”的具体案例 |
| 反转逻辑 | 将“包括A和B”改成“只包括A而不包括B” |
| 遗漏限定 | 去掉影响真假判断的“主要”“之一”等必要限定（仅在确实构成合理考点时） |
| 部分代整体 | 把“教育影响”偷换为它的一个组成部分“教育手段” |
| 调换因果/依据 | 将某类划分的依据偷换为另一类依据（须以材料支持为前提） |

要求：
- **每题至少采用一种实质变式策略**；有原错题时，不得与其题干表达或判断路径基本相同；仅换同义词、修改正误标签不算变式。
- 生成**独立可判定真假的陈述句**，通常 20–60 字；不依赖原题选项、图表或缺失上下文。
- 错误题应有**清晰、真实且具有迷惑性**的误区，避免随意塞入“绝对、全部、永远”等低质量设错词；正确题整句必须成立。
- 每题对概念、范围、分类依据、主体、因果、条件逐项自检；错误题能够定位“错在 X，应为 Y”。
- 在内部记录每题的变式方式，检查题间差异；**最终五字段文本中不增加“变式策略”字段**。

### 3. 写成**可独立复习的微型讲义**（解析深度要求）

逐题按以下思路组织（不是机械堆字）：
1. **精确考点**：4–18 字左右，如“教育影响的构成”，不要只写“教育学基础”。
2. **直接判定**：第一句说明该命题为何正确或错误。
3. **完整概念展开**：**把题干所有决定真假判断的核心概念讲清楚**——定义、性质、构成、划分依据、适用条件、代表人物（仅在确实相关且可靠时）及必要关系。例如题干涉及“教育基本要素”，解析应列出教育者、受教育者、教育影响，并解释各自角色，以及教育内容与手段在教育影响中的位置。
4. **判定依据**：逐一对应题干核心断言；错误题明确写出“错在 X，应为 Y”；正确题解释为何其每项关键关系都成立。
5. **对比/迁移**：附一个真正能帮助区分的邻近概念对照或微情境，避免堆砌无关知识；超出材料而无可靠依据的拓展不要写成权威结论。
6. **独立记忆点**：一句话概括边界、触发词、口诀或对照关系，通常 15–45 字，必须与解析分栏。

解析可在**同一个【解析】字段内**使用 `**概念展开：**`、`**判定分析：**`、`**对比/迁移：**` 等**行内引导词**，但**不得另起空行**或使用任何独立的 `【考点】`、`【记忆点】`、`【判定】` 行。网站使用空行切分题目，应保持单题解析为一个连续段落。可用 `① ② ③` 或 `；` 提高可读性。

使用 `**关键词**` 标记 1–3 处关键定义或概念，供网站高亮；不要输出原始 HTML 标签。目标是**不用查教材也能复习这一题涉及的知识脉络**，但不强制固定字数：简单定义可简明，涉及多个概念需充分展开。

### 4. 输出简要易错点诊断

默认在导入代码块**外**先列 2–5 条短句：`核心：……；易混：……；判题抓手：……`。提供错题时可说明误判陷阱与变式角度；**只有解析**时表述“依据解析推定的考查点”，不要声称知道原题题干。用户指定“只看分析”时，不输出入库题块。

## 输出格式 A：直接粘贴到 edu-quiz（默认；五字段不变）

每题严格依序输出，字段单独占一行且**所有字段都在行首**：
1. `【考点】`：精准命名考点，通常 4–18 字；同源多题分别标注侧重点。
2. `【题干】`：已经变式、独立可判断的陈述句。
3. `【解析】`：**详细概念展开＋判定分析＋对比/迁移**，同一段落内写清，不混入其他标签字段。
4. `【记忆点】`：独立、短而有区分力的判断抓手。
5. `【判定】`：仅允许 `正确` 或 `错误`，必须与**新题干**对应。

**题与题之间恰好一个空行、题内不留空行**。全部题放在**一个纯文本代码块**中，没有编号或额外小标题。速览必须在代码块外。避免解析中出现行首 `记忆点：` 或任何可能被误识别为独立字段的标签。

示例（展示解析深度；示例的新题针对某个知识点作了“部分代整体”变式）：

```text
【考点】教育活动基本要素与教育影响的构成
【题干】某教师认为，教育活动的第三个基本要素就是教学方法，因为方法负责把知识传递给学生。
【解析】该说法**错误**。**概念展开：** 教育活动的基本要素一般包括教育者、受教育者和**教育影响**。教育者是教育活动的组织、引导者，受教育者是学习活动的主体；教育影响是连接双方的中介，既包含教育内容（回答“教什么”，如传授的知识与技能），也包含教育手段（回答“怎么教”，如教学方法与媒介）。**判定分析：** 教学方法属于教育手段，而教育手段只是教育影响的一部分；把教学方法直接等同第三要素，属于“以部分代整体”。**对比/迁移：** 如果教师改变的是授课方式，通常涉及教育手段；如果改变的是所传授的知识主题，则主要涉及教育内容，两者都属于教育影响。
【记忆点】三要素看“教育影响”；教什么是内容，怎么教是手段，不能用手段代替整体。
【判定】错误

【考点】教育影响中内容与手段的区分
【题干】教师将板书改为动画演示，但所教知识不变，这主要是改变教育手段而不是教育内容。
【解析】该说法**正确**。**概念展开：** 教育影响包含教育内容和教育手段。教育内容指教育者要使学习者接触、掌握的知识、技能及相关经验；教育手段指实施教育影响的途径、方式和媒介，包括教学方法及技术工具，两者分别回答“教什么”与“怎么教”。**判定分析：** 此例中知识主题未发生变化，改变的是呈现和传递方式，因此主要变化在教育手段。**对比/迁移：** 若教师由讲解历史知识改为讲解自然科学知识，变化重点则是教育内容；若同一内容从讲授改为讨论，变化重点是教育手段。
【记忆点】内容看知识目标，手段看传递方式；换讲法不等于换知识。
【判定】正确
```

如材料不足以形成无歧义命题，宁可少出并在代码块外说明限制。生成后提醒用户在网站预览核对考点、判定和拓展内容。

## 输出格式 B：JSON 章节包

用户明确要求或批量入库时使用。**保持原结构及字段，不添加变式类型字段**：

```json
{
  "chapters": [
    {
      "name": "教育学 · 第一章",
      "icon": "📘",
      "qs": [
        {
          "s": "<变式题干>",
          "a": false,
          "x": "<完整概念讲解、判定依据、对比迁移；允许**关键词**高亮；不包含独立判定/记忆点标签>",
          "k": "<独立记忆点>",
          "g": "<精确考点>"
        }
      ]
    }
  ]
}
```

- `a` 必须为 JSON 布尔值 `true/false`，不是字符串；`g` 为考点、`k` 为记忆点，不能混入 `x`。
- 一题一个 `qs`，不生成假 ID、假作答历史。JSON 需合法、UTF-8、无尾逗号。
- 可写文件时生成 `edu_quiz_章节包.json`；否则输出一个 JSON 代码块，指导保存。
- 网站「更多 → 数据迁移 → 导入章节包 / 备份」会**新增**章节，若同名可能重复。若要追加到现有章节，优先使用格式 A。

## 输出质量自检（不可省略）

1. **输入溯源**：哪些主张来自原解析，哪些是可靠的一般性拓展？有不确定或不同教材口径时是否明确限制？
2. **变式合规**：提供错题时每题是否至少采用一种有实质变化的策略？是否避免直接照搬原题和仅替换同义词？
3. **可判定性**：新题是否独立成立？错误题能否精确指出“错在 X，应为 Y”？正确题是否每个关键断言都成立？
4. **讲义深度**：题干涉及的全部核心概念是否说明定义/分类/构成及适用条件？是否解释判断依据并提供有意义的对比或迁移？
5. **字段独立**：考点 `g` 与记忆点 `k` 是否各司其职？解析 `x` 中是否没有独立的尾随“记忆点/判定”标签？
6. **导入兼容**：格式 A 必须按【考点】【题干】【解析】【记忆点】【判定】顺序，题间一个空行、题内无空行；格式 B 的 `s/a/x/k/g` 全部完整，`a` 是布尔值。
7. **质量与去重**：不为凑数复制或同义重复；答案分布自然；关键词高亮 1–3 处；不捏造来源。
